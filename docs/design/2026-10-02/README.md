# Дэшборд по референсу

Старая главная и пять её карточек удалены. Главная создана заново в
`Pages/Dashboard.cshtml`, `_DashboardReferenceLayout.cshtml`,
`_DashboardReferenceWidget.cshtml` и `wwwroot/css/dashboard-reference.css`.
Она не подключает прежние `dashboard-refresh.css` и `dashboard-design.css`.
Общие формы, редактор виджетов и страницы других разделов продолжают работать.

- `/Dashboard` — новая композиция с данными текущего пользователя.
- `/Dashboard?Reference=true` — та же композиция с именем, датой, числами,
  недельным планом и точками графика из предоставленного изображения.
  Этот визуальный снимок не записывает демонстрационные значения в базу.

Фотографии гантелей, штанги и аватар взяты непосредственно из исходного
референса: CSS показывает только нужные участки `reference-art.png`.
Все надписи, карточки, элементы управления, логотип и график — HTML/CSS/SVG.
Иконки главной вынесены в отдельный `DashboardReferenceIconTagHelper`.

Снимки:

- `dashboard-reference.png` — режим с содержимым референса, 1547 × 1017.
- `dashboard-live-desktop.png` — рабочий дэшборд на изолированных тестовых данных.
- `dashboard-mobile.png` — рабочий дэшборд на ширине 390 px.

Проверены сборка .NET, существующие интеграционные сценарии AdminSmoke,
доступ и сохранение пользовательских раскладок, быстрый старт и продолжение
тренировки, цели и привычки. Проверка Playwright: 1547, 1440, 1024, 768,
390 и 320 px, отсутствие горизонтального переполнения и ошибок JavaScript,
поиск, открытие быстрого старта, деталей занятия, привычек и редактора.

Сборка выполнялась в отдельную папку `.artifacts`, поскольку запущенное
приложение удерживает стандартные файлы `bin/Debug/net10.0`.
Для просмотра новых Razor-шаблонов уже запущенное приложение нужно пересобрать
и перезапустить.

Вкладка «Тренировки» перенесена в новый общий макет:

- `/Dashboard/Workouts` — история, статистика, расписание и состав занятий пользователя.
- `/Dashboard/Workouts?Reference=true` — содержимое второго референса: октябрь 2026,
  четыре занятия в истории и четыре упражнения выбранной тренировки.
- `workouts-reference.png` — снимок на исходном размере 1546 × 1017.
- `workouts-mobile.png` — снимок на ширине 390 px.

Фотографии взяты из нового референса через CSS-окна в `workouts-reference-art.png`.
Сохранён предыдущий логотип с наклонными полосками по отдельной просьбе пользователя.
История поддерживает неделю, месяц и год, поиск по занятиям и упражнениям, фильтр
программ, выбор дня и выбор занятия. Запланированные дни открывают соответствующую
тренировку или программу. Быстрый старт, шаблоны, повтор и продолжение используют
существующие защищённые обработчики. Показатели считают завершённые рабочие подходы,
исключая разминку; клиентский контекст проверяется до загрузки данных.

Пройдены сборка, AdminSmoke и браузерные сценарии поиска, фильтров, выбора даты,
упражнений, диалогов, запуска и продолжения тренировки. Проверены ширины 1546,
1440, 1280, 1024, 768, 390 и 320 px без ошибок JavaScript и горизонтального переполнения.
