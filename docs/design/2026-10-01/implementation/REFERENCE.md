# Дэшборд по приложенному референсу

Главная `/Dashboard` сверстана по изображению пользователя размером 1547 × 1017.
Стили находятся в `enx-fit/wwwroot/css/dashboard-reference.css` и подключены после
существующих стилей. Разметка остаётся серверной Razor, значения берутся из аккаунта.

Фотографии оборудования и аватар отображаются отдельными CSS-спрайтами из
`enx-fit/wwwroot/images/dashboard/reference-art.png`. Это копия приложенного
референса. Интерфейс, текст, кнопки, календарь и график реализованы HTML/SVG;
страница не заменена изображением. Генерация картинок не потребовалась.

Восстановлены боковая навигация, верхняя панель, блок старта тренировки,
недельный план, следующая цель, последняя тренировка, три показателя,
график рабочего веса, параметры тела и привычки. Сохранены пользовательские
раскладки и режим тренера. Для сброса ранее сохранённой раскладки:
«Настроить виджеты → По умолчанию → Сохранить».

Кнопка подтверждения предложения открывает существующее подтверждение
в программе. График показывает фактические подходы упражнения из следующей
цели, а при отсутствии таких результатов — последнего записанного упражнения.
Доступны периоды 2, 4 и 6 недель. Стрелки календаря переключают недели.
«Чтение» сохраняется в ежедневной записи, как сон и вода.

Добавлена миграция `20261001120613_DashboardReadingMinutes`.
Она добавляет `DailyCheckIns.ReadingMinutes` с начальным значением 0.
Приложение применяет миграции своим существующим механизмом при запуске;
при проверке рабочая база не изменялась. После изменения исходников
нужно пересобрать и перезапустить запущенный экземпляр приложения.

## Проверка

- Сборка приложения и AdminSmoke успешна.
- AdminSmoke: пройдены проверки авторизации, раскладки, программ, тренировок
  и ежедневных записей, включая сохранение и валидацию минут чтения.
- EF: модель совпадает с последней миграцией.
- Edge / Playwright: 1547, 1440, 1024, 768, 390 и 320 px; без горизонтальной прокрутки.
- Проверены поиск, быстрый старт, шаблоны, детали занятия, предложение нагрузки,
  недели, периоды графика, сохранение чтения, отмена редактирования виджетов
  и мобильная навигация. Ошибок JavaScript не обнаружено.
- При сборке остаётся существующее предупреждение NU1901 в тестовом проекте
  о его зависимости NuGet.Protocol 6.12.1.

Скриншоты: `dashboard-reference-desktop.png` и `dashboard-reference-mobile.png`.
Демонстрационные значения задаются только в SQLite в памяти; в рабочем аккаунте
даты, программа, показатели и состояния зависят от его данных.

## Изолированный просмотр

```powershell
dotnet build tests/AdminSmoke/AdminSmoke.csproj --no-restore -p:UseAppHost=false -p:BaseOutputPath=E:/Net/enx-fit/.artifacts/reference-build/
dotnet .artifacts/reference-build/Debug/net10.0/AdminSmoke.dll --serve --reference-preview --port 5192
```

Адрес: `http://localhost:5192/Dashboard`.
Тестовый вход: `reference@example.test`, пароль `TestOnly!2026`.
Этот аккаунт существует только во временной базе тестового процесса.
