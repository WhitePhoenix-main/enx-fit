# Перенос дэшборда

Композиция референса `02-dashboard.png` перенесена в `/Dashboard`.
Снимки в этой папке показывают работающие Razor-страницы с локальными
тестовыми данными SQLite в памяти:

- `dashboard-desktop.png` — личная главная, 1440 px.
- `dashboard-mobile.png` — личная главная, 390 px.
- `dashboard-coach.png` — просмотр назначенного клиента.

Карточки подключены к существующим сценариям начала/продолжения занятия,
шаблонов, истории, программы, целей и привычек. Рабочий вес показывает
только фактически выполненные подходы. Предложение нагрузки проходит
проверку актуальности и открывает существующее подтверждение в программе.

Основные файлы: `dashboard-design.css`, `_DashboardWorkoutStart.cshtml`,
`_DashboardNextGoal.cshtml`, `_DashboardLastWorkout.cshtml`,
`_DashboardStrength.cshtml`. Подробности — в `DASHBOARD.md` в корне проекта.

Новая композиция применяется по умолчанию. Сохранённые ширины, порядок
и видимость карточек остаются. Для перехода на новую композицию:
«Настроить дэшборд → По умолчанию → Сохранить».

Проверка: сборка решения, AdminSmoke (включая расчёты графика,
фильтрацию устаревших рекомендаций, отсутствие изменений на GET,
доступ к последнему занятию вне выбранного периода), браузер на
320, 390, 768, 1024 и 1440 px. Проверены диалоги быстрого старта,
деталей занятия, настройки раскладки и мобильного меню; оба режима
доступа и пустое состояние нового аккаунта.
