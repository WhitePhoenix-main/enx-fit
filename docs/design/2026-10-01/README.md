Дата: 1 октября 2026. Результат: **12 графических листов — 9 страниц сайта и 3 мобильных листа с 11 экранами**. Изображения созданы встроенным `image_gen`; полный набор запросов сохранён в [prompts.json](prompts.json).

### Точный состав меню

- Спортсмен, десктоп: Главная, Тренировки, Программы, Прогресс, Библиотека; внизу Профиль и Настройки. Привычки остаются второстепенными.
- Спортсмен, телефон: Главная, Тренировки, Программы, Прогресс, Ещё. Профиль, библиотека и привычки находятся в «Ещё».
- Активная тренировка, телефон: скрыть обычную нижнюю навигацию; оставить возврат с сохранённым состоянием и главное действие подхода.
- Тренер: явное переключение «Кабинет тренера / Моя статистика»; обзор, клиенты, программы, решения. На телефоне — Обзор, Клиенты, Программы, Ещё.
- Администратор: Обзор, Пользователи, Тренеры, Упражнения, Программы; дополнительные журнал и настройки. На телефоне — Обзор, Пользователи, Каталог, Ещё.

## Главные сценарии

1. **Есть активная сессия:** карточка «Продолжить тренировку» заменяет обычный старт и получает первый визуальный приоритет. Повторное начало возвращает ту же сессию.
2. **Нет активной сессии:** главное действие — занятие по программе; альтернативы — пустая, из шаблона и повтор. Названия объясняют источник и последствия.
3. **Ввод:** план и прошлый результат — подсказки, сегодняшний факт — отдельные поля. Фактический RIR не подставляется из прошлого или цели; отсутствие оценки не мешает сохранить занятие.
4. **Завершение:** показать выполненные и оставшиеся подходы; дать завершить частично, вернуться или исправить. Сохранение результата и вычисление рекомендации имеют отдельные статусы.
5. **Решение:** нагрузка, причина, исходные занятия, границы применимости и автор назначения. Порядок «посмотреть → подтвердить/изменить/оставить»; новая цель не применяется от просмотра карточки.
6. **Тренер:** причина внимания → записи клиента → решение с комментарием → автор и время. В режиме согласования клиент видит ожидание тренера вместо кнопки окончательного применения.
7. **Аккаунт:** своя история, экспорт и исправления доступны независимо от оплаты; условия подписки и тренерского доступа объясняются отдельно.

## Состояния для последующей вёрстки

| Состояние | Что показать |
| --- | --- |
| Первый вход | Короткий подбор программы или «Начать без программы»; графики без вымышленных данных. |
| Загрузка | Скелет только загружаемого блока, устойчивый каркас страницы. |
| Пустая история / период | Объяснение и действие: начать тренировку либо выбрать другой период. |
| Нет результатов поиска | Сохранить запрос, дать сбросить фильтры или создать личный вариант. |
| Черновик подхода | «Не сохранён» рядом с конкретной записью; отдельная кнопка сохранения. |
| Сохранение | «Сохраняем…», затем «Сохранено»; не сообщать об успехе до подтверждения. |
| Плохая связь | «Сохранено на устройстве · ожидает отправки» только после внедрения локального хранения; количество ожидающих операций и повтор отправки. |
| Ошибка | Конкретное поле или действие, введённые значения остаются. |
| Конфликт | Показать версию и автора изменения, дать выбрать дальнейшее действие. |
| Недостаточно данных | Назвать причину: нет RIR, неполные подходы, смена режима, перерыв; не рисовать уверенную нагрузку. |
| Частичное завершение | Перечень невыполненного и причина; факт занятия отдельно от полного выполнения плана. |
| Связь с тренером завершена | История клиента сохранена; недоступные действия согласования явно обозначены. |

## Что уже есть, а что проектируется

Существующая база: лендинг, дэшборд, разделы тренировок и прогресса, библиотека, программы, Quick Workout и активные сессии, роли и назначенные клиенты, админский обзор, Identity-профиль.

Концепция расширяет или унифицирует: следующий шаг на главной, политику прогрессии и объяснения, полный цикл подтверждения, приглашения и комментарии тренера, локальные черновики и очередь отправки, управление подпиской, тренировочный экспорт/импорт и общий каркас аккаунта. Некоторые элементы анализа и принятия рекомендаций уже существуют; показанный законченный сценарий требует доработок из чеклиста.

Цены **349 ₽ / месяц** и **1 390 ₽ / месяц**, пакет до пяти клиентов — гипотезы пилота из новой спецификации. Референс не подтверждает рабочую оплату, готовые лимиты или доступность всех изображённых возможностей. Не обещать на публичном лендинге функции до их реализации.

## Проверка изображений и точность

Все 12 листов просмотрены визуально: сохранены палитра, бренд, основные композиции; мобильные экраны не обрезаны. Это растровые референсы, поэтому мелкие подписи, даты, номера дней, иллюстративные значения и состав вторичных пунктов меню могут различаться между листами. При реализации источником точных правил служат этот документ, чеклист и спецификация прогрессии, а не автоматически нарисованные числа.

Пример `60 → 62,5 кг` показывает композицию предложения. Он не задаёт универсальный шаг или правило повышения. В частности, после смены диапазона нельзя считать наблюдения сопоставимыми без проверки; будущие даты на иллюстративном графике не должны отображаться как фактически выполненные результаты.

На листе библиотеки нижний блок «Ничего не найдено» — отдельный пример пустого состояния; он не должен появляться одновременно с найденными карточками. На листе активного занятия нижняя полоса потери связи — отдельный вариант состояния. Дни отдыха не входят в число выполненных тренировок. Роль и тариф не смешиваются даже там, где условные строки нарисованы неодинаково.

## Локальный просмотр

Можно открыть `index.html` напрямую в браузере. Для просмотра через localhost, из этой папки:

```powershell
node serve.cjs
```

Адрес: `http://127.0.0.1:5199`. Сервер раздаёт только материалы этой папки и не подключается к базе приложения.
